# Main Figure 2

## Status

Partial scientific source package. The retained COMSOL models support the
resonator geometries and representative pressure fields in panels (a) and (c).
The final geometry renders, original panel (b) photograph, labels, and assembled
layout were not located.

## Files

- `largeResonator_quarter.mph`: quarter-symmetry large-resonator model.
- `inWall_resonator.mph`: in-wall resonator model.

The models require COMSOL Multiphysics 6.3. No claim is made that opening them
alone reproduces the exact saved camera views, color limits, or annotations.

The two `.mph` files are not duplicated in this folder in the Git repository.
Use the identical copies in `numerical_model/` at the repository root.

Original release paths: `numerical_model/largeResonator_quarter.mph` and
`numerical_model/inWall_resonator.mph`.
