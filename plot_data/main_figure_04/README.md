# Main Figure 4

## Status

Complete retained waveform data and MATLAB plotting code. The script reproduces
the four stacked raw/processed traces. The final manuscript callouts and panel
annotations were added manually and their editable source was not located.

## Files

- `fig4_gen.m`: loads and plots the waveform traces; its second figure is Main Figure 9.
- `HT06ex.mat`: raw ECG and audio arrays.
- `HT06filt.mat`: processed ECG and audio arrays.

Run `fig4_gen.m` in MATLAB with this directory as the working directory. Figure
window 1 is the numerical basis of Main Figure 4. Original release paths are in
`figures/`.
