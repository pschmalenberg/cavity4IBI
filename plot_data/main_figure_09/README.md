# Main Figure 9

## Status

Complete retained MATLAB plot source and numerical data. Main Figure 9 is the
second figure generated by the same script used for Main Figure 4.

## Files

- `fig4_gen.m`: computes `abs(fft(y_filt))`, normalizes it by trace length, and plots 0 to 65 Hz on a logarithmic y-axis.
- `plot_figure_09.m`: standalone extraction of that FFT section.
- `HT06filt.mat`: contains the processed audio array `y_filt`.

Run `plot_figure_09.m` in MATLAB with this directory as the working directory.
The original combined `fig4_gen.m` also loads `HT06ex.mat` for Main Figure 4;
that file is included in `../main_figure_04` and is not required for the Figure
9 FFT calculation itself. Original release paths: `figures/fig4_gen.m` and
`figures/HT06filt.mat`.
